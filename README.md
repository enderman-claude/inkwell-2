# inkwell-2

Prototype for the inkwell-2 interface: the drawing pad with the rope stabiliser, the colour picker, and the brush slots with the quick access menu.

Open `prototype/index.html` in a browser, or see the deployed page once GitHub Pages is enabled.

## Prototype controls

- Draw with a pen, mouse, or touch. The stabiliser slider sets the rope length.
- Colour picker: drag the diamond for saturation and value, and the ring for hue. Tap a swatch to link it, then edits update that swatch.
- Brush slots: slots 1 to 3 are on the bar, and "More" opens the quick access menu for slots 4 to 9. The menu closes when you tap "More" or anywhere outside it, and stays open after you pick a slot.
- Keys 1 to 9 select a slot on PC.

## Not in this prototype

- Presets persistence, the diamond old/new split, and the close snapshot from the picker draft.
- Brush settings beyond size, hardness, and colour difference.
- Layers, selection, fill, transform, file format, and dock system.
